# สมศรี — แอปจดบัญชี (Android)

แอปมือถือของสมศรี ใช้ Google Sheet + Apps Script ตัวเดียวกับบอท Telegram

- แก้หน้าแอปที่ `www/index.html`
- push ขึ้น `main` แล้ว GitHub Actions จะสร้างไฟล์ APK ให้ที่หน้า **Releases**
- repo นี้ต้องเป็น **private** เพราะมีกุญแจเซ็นแอป (`android/app/somsri.keystore`)
